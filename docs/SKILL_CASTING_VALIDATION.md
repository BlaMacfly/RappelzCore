## Implemented lifecycle and limits

`RestorationBook` accepts only fixed self-MP restoration with supported zero conditions/costs, no MAtk/percentage/state/AoE component, ordinary active validity and unenhanced base levels. Unsupported effects, targets and costs are refused. Prices, effect amounts and durations have checked wide bounds. Modifiers, equipment bonuses, casting-speed stats, state effects, HP healing, damaging casts, summons and job advancement remain unfinished.

The normal **CS_SKILL (400)** route requires a live owning player, learned requested level, matching self caster/target/layer, finite coordinates, sufficient HP/MP, no active motion/attack/cast and no cooldown. Positions/effects come from authoritative server state. Foreign, unknown, passive/unsupported, zero-level, unlearned and cooldown requests receive ordinary game refusals, without a fatal connection dialog or debit.

Start broadcasts CASTING without cost. FIRE rechecks live identity, life, layer, position/movement and MP before applying the entire cost and effect once. Accepted movement, explicit cancellation, teleport/layer change, a normal attack, logout and invalid/dead state cancel the pending cast. Canceled casts have no charge, restoration or cooldown. Learning is refused while a cast is pending so the private learned-list snapshot cannot become stale. Unit tests cover forged requests, insufficient MP, delayed fire, cancellation, hidden layers/disconnect and real handler ownership/learned-level checks without reachable SQL.

The post-fire value is `min(maxMP, previousMP - cost + nominal restoration)`. Reference [MPHealByItem](https://github.com/NGemity/RZEmulator/blob/38ceb2c6065fabf6ff4ba71d52f955f362c6c839/Chihiro/src/Entities/Unit/Unit.cpp#L2571) returns a nominal amount separately from capped state, so the wire hit reports **3500**, not the net capped gain. HPMP reports the actual final value and delta. Costs and recharge start at FIRE, consistent with [SKILL_CAST_COST=0](https://github.com/NGemity/RZEmulator/blob/38ceb2c6065fabf6ff4ba71d52f955f362c6c839/Chihiro/src/Globals/GameRule.h#L45) and [ProcSkill](https://github.com/NGemity/RZEmulator/blob/38ceb2c6065fabf6ff4ba71d52f955f362c6c839/Chihiro/src/Skills/Skill.cpp#L838).

Cooldowns use a monotonic wide clock and **character GUID/group**, surviving a new session handle on the same world process. Private full SKILL_LIST packets carry total/remaining centiseconds at FIRE and character login. Expired entries are pruned; the table is bounded to 8192 live entries. Cross-skill sharing is a local group policy, not a verified original mechanic. **Cooldowns are not stored across a worldserver restart**. Vitals use the existing live-state/autosave/logout persistence; no new SQL schema or synchronous per-cast durability guarantee was added.

## Wire and client/Lua state

CS_SKILL remains the retained 31-byte layout; decoding now rejects trailing/truncated/nonfinite requests. The existing SC_SKILL (401) header is reused. The checked restoration subset uses CASTING=1 with **duration u32**, error u16, three zero pad bytes; CANCEL=3 with nine zero bytes; FIRE=0 with one ADD_MP=21 hit **type u8, target u32, final MP i32, nominal amount i32**. [Primary layout](https://github.com/NGemity/RZEmulator/blob/38ceb2c6065fabf6ff4ba71d52f955f362c6c839/shared/Server/Packets/GameClient/TS_SC_SKILL.h#L142) and [duration assembly](https://github.com/NGemity/RZEmulator/blob/38ceb2c6065fabf6ff4ba71d52f955f362c6c839/Chihiro/src/Skills/Skill.cpp#L650) corroborate field meanings. Local retained evidence establishes the useful 13-byte ADD_MP entry; the public serializer pads its union to 45. Rust emits the compact 70-byte FIRE frame and accepts that form or the 32 extra zero bytes. Original-client interoperability remains untested.

The K window shows actual active/passive classification, supported **Lancer**, cost/incantation/recharge, countdown and **Annuler**. It does not grant or debit locally on button press. Only confirmed matching CASTING/FIRE/CANCEL events of the owner or currently visible same-layer entities enter the adapter; malformed/foreign/duplicate phases are ignored. A confirmed FIRE applies its post-effect vitals **before Lua callbacks**, then the following identical HPMP does not repeat the change. Completion arriving without a previously observed matching CASTING is ignored by this presentation subset; HPMP still updates actual vitals. Broader late-observer cast reconstruction remains future work.

Read-only Rappelz event **RAPPELZ_SKILL_EVENT(skill_id, phase, caster_handle, nominal_amount)** uses phase CASTING/CANCEL/FIRE, amount zero except FIRE. RappelzDebug logs these arguments and reads current real vitals. Identical snapshots and UI reload do not replay cast events. No Lua casting/action API was exposed. Physical K/new mouse-button activation remains a manual check; the native driver uses the production request helper, network, adapter, Lua and renderer.
